# Ridership Report Tool

A small full-stack DX tool for a railway & bus operator: upload passenger CSV data, see a dashboard, and download an automated Excel report with plain-language findings.

**Problem it solves:** staff spend hours each week copying ticket/IC-card counts into Excel and writing the same summary. This tool cleans the data, stores it, and produces the report in one click.

> Sample data in `data/` is **synthetic** (generated by `data/generate_sample_data.py`). Station names are used for realism only.

## Features
- CSV upload with row-by-row validation (bad rows are rejected with the reason)
- Re-uploading the same file does not double-count (database upsert)
- Filters: date range and line
- KPIs: total, daily average, busiest station, peak hour, % change vs previous period
- Charts: daily trend, by station, average by hour
- Rule-based "key findings" in plain English
- One-click Excel report (Summary, Daily, Stations sheets with charts)
- Automated tests (pytest)

## Run it (Windows)
Needs Python 3.10+.
```bash
cd Ridership
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```
Open http://127.0.0.1:8000, upload `data/sample_ridership.csv`.
API docs: http://127.0.0.1:8000/docs

Run tests: `pytest`
